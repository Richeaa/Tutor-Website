# 🎓 Flick Tutor

**Flick Tutor** is a modern, responsive website designed to provide a smooth user experience for an educational platform. Built using **HTML**, **CSS**, and **JavaScript**, the project integrates the **Bootstrap** library for streamlined styling and responsiveness. A key feature of the website is the **light/dark mode toggle** for user personalization.

## 🌐 Live Preview

[🔗 Visit Flick Tutor Website](#) *https://richeaa.github.io/Tutor-Website/*

## ✨ Features

- ✅ **Responsive Design** — Mobile-first layout using Bootstrap’s grid system.
- 🌗 **Light/Dark Mode Toggle** — Users can switch between light and dark themes.
- 🎯 **Clean Navigation** — Simple, intuitive structure for accessing sections like Home, About, Product, and Contact.
- 💡 **User-Centric Interface** — Designed for ease of use and readability.

## 🛠️ Tech Stack

- **HTML5** — Markup structure
- **CSS3** — Custom styling
- **JavaScript** — Toggle logic
- **Bootstrap 5** — Layout, responsiveness, and UI components
